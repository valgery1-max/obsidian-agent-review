# Agent Review для Obsidian

Agent Review — инструмент профессиональной совместной работы над текстом с ИИ внутри Obsidian. Редактор оставляет комментарии к конкретным фрагментам или всему документу, получает предложения агента в контексте задачи и принимает решение по каждой правке.

Плагин подключает локальные CLI Codex и Claude Code, отображает обсуждение на полях Markdown-файла и помогает вести последовательную редактуру. Человек сохраняет контроль над исходным текстом, областью работы и финальным вариантом документа.

## Возможности

- подключение Codex и Claude через установленные локальные CLI;
- комментарий к выделению и комментарий ко всему документу;
- отдельная ветка обсуждения для каждого комментария;
- дополнительные замечания в той же ветке и продолжение одной правки, если результат требует доработки;
- выбор или создание задачи агента для текущего файла;
- цель задачи, дополнительные файлы и контекст из хранилища;
- чат с историей задачи, прикреплёнными файлами, изображениями из буфера и доступными навыками;
- инструкции для агента на уровне файла, папки или всего хранилища;
- просмотр предложенных изменений прямо в редакторе;
- принятие или отмена отдельной правки, а также принятие всех доступных правок;
- история версий документа и восстановление выбранной версии;
- статусы обработки, остановка задачи и восстановление состояния интерфейса после перезапуска Obsidian.

Идентификатор плагина сохранён как `codex-review`, а текущая версия — `0.25.3`. Благодаря этому существующие данные Agent Review продолжают находиться в прежнем каталоге плагина.

## Подключение агентов

### Codex

1. Установите Codex CLI и выполните вход через подписку ChatGPT.
2. Откройте `Настройки -> Agent Review`.
3. Проверьте путь к команде Codex. По умолчанию используется `codex`; при необходимости укажите полный путь к исполняемому файлу.
4. Откройте Markdown-файл, выберите Codex, затем выберите существующую задачу или создайте новую.

Agent Review запускает локальный Codex App Server через CLI. Встроенный клиент принимает изменения файлов от Codex и отклоняет запросы на произвольное выполнение команд.

### Claude

1. Установите Claude Code и один раз выполните вход в Claude Code.
2. В `Настройки -> Agent Review` проверьте путь к команде Claude. По умолчанию используется `claude`.
3. Откройте Markdown-файл и выберите Claude в панели Agent Review.
4. Выберите существующую задачу Claude Code или создайте новую.

История Claude Code читается из стандартного локального каталога Claude Code. Отдельная настройка API-ключа в Agent Review не требуется: авторизация выполняется средствами локального Claude Code.

## Рабочий процесс редактора

1. Откройте Markdown-файл в режиме редактирования.
2. Выберите агента, задачу и модель в верхней панели Agent Review.
3. Выделите фрагмент и нажмите кнопку комментария к выделению. Для общей редакторской задачи используйте комментарий ко всему документу.
4. Сформулируйте замечание и отправьте его агенту. Ответ появится в карточке комментария на полях документа.
5. Добавьте уточнение в ту же ветку, когда требуется продолжить обсуждение. После ответа агента можно продолжить ту же задачу и попросить переработать предложенную правку.
6. Откройте предложенные изменения в тексте, примите или отмените отдельную правку. Панель статуса также позволяет принять все доступные правки.
7. Используйте разделы `Чат`, `Все комментарии` и `Версии` для общего контекста, навигации по обсуждению и восстановления документа.

### Рабочая копия

В начале обработки плагин создаёт локальную рабочую копию документа в каталоге данных плагина. Агент читает и изменяет эту копию, пока редактор может продолжать работу с исходным документом.

После завершения задачи Agent Review переносит изменения по совпадающим фрагментам и их окружению. Правки, затронутые параллельной пользовательской редактурой, помечаются для проверки, а текущий текст редактора сохраняется. Перед принятием каждой правки можно увидеть её сравнение с текущей версией документа.

## Инструкции, задачи и контекст

Инструкции для агента можно сохранять на уровне текущего файла, папки или всего хранилища. В задаче доступны цель, дополнительные файлы и контекст из открытого хранилища. Чат сохраняет историю выбранной задачи и позволяет продолжить работу после нового запуска Obsidian.

Комментарии к выделению подходят для точечной стилистической, фактологической или структурной работы. Комментарий ко всему документу передаёт агенту задачу в масштабе всего текста с подходящим объёмом контекста. Ветка комментария связывает исходное замечание, ответ агента и последующие уточнения.

Раздел `Версии` хранит версии документа, созданные до и после работы агента, после принятых изменений и при восстановлении. Восстановление записывает выбранную редакцию в файл и сохраняет текущую редакцию в истории.

## Требования

- Obsidian Desktop версии `1.7.2` или новее;
- Node.js 18 или новее для сборки из исходников;
- Codex CLI для работы с Codex;
- Claude Code для работы с Claude;
- локально выполненный вход в выбранный CLI;
- доступ к Markdown-файлам хранилища для создания рабочей копии.

Основной проверенный сценарий — Obsidian Desktop на Windows. В коде предусмотрены различия путей и запуска процессов для macOS, а живой прогон на macOS требует отдельной проверки.

## Ручная установка

1. Соберите плагин из исходников или возьмите подготовленные файлы `manifest.json`, `main.js` и `styles.css`.
2. Создайте каталог `<Хранилище>/.obsidian/plugins/codex-review/`.
3. Скопируйте в него эти три файла.
4. В Obsidian откройте настройки сторонних плагинов, включите Agent Review и настройте пути к CLI.

Каталог установки использует идентификатор `codex-review`, даже если репозиторий называется `obsidian-agent-review`.

## Сборка из исходников

```bash
git clone https://github.com/valgery1-max/obsidian-agent-review.git
cd obsidian-agent-review
npm ci
npm run check
npm test
npm run build
```

Команда `npm run build` создаёт production-сборку `main.js` из `src/main.ts`. Для разработки с пересборкой используйте `npm run dev`.

## Приватность и локальные данные

Agent Review запускает выбранный CLI локально. В запрос к агенту могут входить текст документа, выделение, комментарии, инструкции, цель задачи, выбранный контекст и прикреплённые файлы. Дальнейшая обработка и хранение этих данных определяются Codex, Claude Code и вашей авторизацией у соответствующего провайдера.

Настройки, комментарии, статусы обработки и история версий хранятся в локальных данных плагина Obsidian. Рабочие копии и временные вложения также создаются локально. История Claude Code находится в стандартном каталоге Claude Code. Перед публикацией содержимого хранилища проверьте `data.json`, каталоги `.obsidian` и рабочие копии.

Плагин предназначен для локального рабочего процесса внутри Obsidian Desktop и не заменяет политику доступа или конфиденциальности используемых CLI. Укажите только те файлы и источники, которые разрешено передавать выбранному агенту.

## Ограничения текущего состава

- интерфейс и manifest рассчитаны на Obsidian Desktop; мобильный Obsidian не входит в поддерживаемый сценарий;
- для работы агента требуется установленный и авторизованный локальный CLI;
- результат агента требует редакторского просмотра перед принятием;
- перенос изменений зависит от совпадения исходного фрагмента и его окружения с текущим документом;
- поддержка macOS подготовлена на уровне кода, а основной практический прогон выполнен на Windows.
